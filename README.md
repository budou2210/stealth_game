# ステルスゲーム

警備員の目と耳をかいくぐり、マップに散らばった8個のアイテムを集めて出口から脱出するゲームです。

## 必要なもの

- Windows / Mac / Linux のパソコン
- [uv](https://docs.astral.sh/uv/)（Pythonやゲームに必要なものを自動で用意してくれるツール）

uv が入っていなければ、次のコマンドでインストールします。

Windows（PowerShell）:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Mac / Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## 起動

ゲームのフォルダ（`stealth_game`）で次のコマンドを実行します。初回だけ、必要なものの準備に少し時間がかかります。

```bash
uv run stealth-game
```

ハイフン（`stealth-game`）です。アンダーバー（`stealth_game`）では起動しません。

## 遊び方

- マップに散らばった**8個のアイテム（黄色）**を全部集めて、**右上の出口**へ向かいましょう。出口は全部集めると赤から緑に変わります。
- 警備員の**視界（床に映る扇形）**に入り続けると気づかれ、「！」が出て追いかけてきます。触れられると捕まります。
- **走ると足音**で近くの警備員に気づかれます。Shiftを押しながら歩く**忍び足**なら足音は出ず、見つかりにくくなります。
- スタート地点の小部屋は**安全地帯**です。ここでは見つからず、警備員も入ってきません。ただし一度外に出ると扉が閉まり、戻れません。
- 警備員は2種類います。**青**は決まった道を見回り、**紫**は気まぐれに歩き回ります。
- 警備員を見失わせても、最後に見た場所や逃げた方向を探しに来ます。油断は禁物です。

### お助けアイテム

20秒おきにマップに現れます。拾うと持ち歩けて、好きなときに使えます。

| アイテム | 色 | キー | 効果 |
|---|---|---|---|
| 透明化 | 白 | E / . | 10秒間、警備員の目に映らず、触れても捕まらない（足音は聞かれる） |
| スタン | ピンク | Q / / | その瞬間あなたを見ていた警備員は10秒、周りの警備員は5秒、動けなくなる |
| 音の罠 | 水色 | Space / \ | 足元に置くと3秒後に大きな音が鳴り、周りの警備員がそこへ調べに行く |

難易度によって出るアイテムが違います（下の表）。

## 難易度

| 難易度 | ライフ | お助けアイテム | ひとこと |
|---|---|---|---|
| 簡単 | 3 | 3種 | 青い警備員だけ。まずはここから |
| 普通 | 2 | 3種 | 紫の警備員がうろつき始める |
| 難しい | なし | 透明化・音の罠 | 警備員が鋭くなり、仲間を呼ぶ |
| 激ムズ | なし | 透明化・音の罠 | 遠くの警備員が回り込んで挟み撃ちにしてくる |
| 地獄 | なし | なし | 見つかった瞬間に追ってくる。助けは何もない |

- ライフがある難易度では、捕まるとアイテムを2個落としてスタート地点に戻されます。ライフがなくなる（またはライフのない難易度で捕まる）とゲームオーバーです。
- 難しい以上では、アイテムを全部集めると紫の警備員があなたを決して見失わずに追ってきます。このとき、お助けアイテムは紫の警備員には効きません。

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| Shift | 忍び足 |
| E / . | 透明化を使う |
| Q / / | スタンを使う |
| Space / \ | 音の罠を置く |
| Tab | 視点の切り替え（全体 → 中間 → 近い） |
| F | 設定：足音の範囲の表示のオン・オフ |
| R | 同じ難易度でやり直す |
| M | 難易度選択に戻る |
| Esc | 終了 |

難易度選択の画面では、↑↓で選んでEnter（または1〜5キー）で始めます。

## 設定

- **足音の範囲の表示（F）**: 走っている間、足元に「足音が届く範囲」を表示します。外側の輪が見通しのよい場所で届く距離、内側の薄い円が壁越しでも届く距離です。追跡中の警備員は、これより少し遠くの足音まで聞き取ります。最初はオンで、難易度選択の画面でもプレイ中でも切り替えられます。

## うまくいかないとき

- **「\」キーが反応しない**: 日本語キーボードでは、「\」が「¥」や「ろ」のキーに割り当てられていて反応しないことがあります。音の罠は Space キーでも置けます。
- **文字が英語で表示される**: 日本語のフォントが見つからない環境では、英語で表示されます。
