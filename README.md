# スニーキューブ（SNEAKUBE）

警備員の目と耳をかいくぐり、マップに散らばった8個のアイテムを集めて出口から脱出するゲームです。

## 必要なもの

- Windows / Mac / Linux のパソコン
- [uv](https://docs.astral.sh/uv/)（Pythonやゲームに必要なものを自動で用意してくれるツール）

uv が入っていなければ、次のコマンドでインストールします。

Windows（PowerShell）:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Mac / Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## ダウンロード

1. このページの上にある緑の「**Code**」ボタンを押し、「**Download ZIP**」を選びます。
2. ダウンロードした ZIP ファイルを展開します。`stealth_game-main` というフォルダができます。

Git を使える人は、`git clone https://github.com/budou2210/stealth_game.git` でもかまいません（この場合のフォルダ名は `stealth_game` です）。

## 起動

1. 展開したフォルダ（`stealth_game-main`）でターミナルを開きます。
   - Windows: フォルダを開き、上のアドレス欄に `powershell` と入力して Enter を押すと、そのフォルダで PowerShell が開きます。
   - Mac: Finder でフォルダを右クリックし、「フォルダに新規ターミナル」を選びます。
2. 次のコマンドを実行します。初回だけ、必要なものの準備に少し時間がかかります。

```bash
uv run stealth-game
```

ハイフン（`stealth-game`）です。アンダーバー（`stealth_game`）では起動しません。

## 遊び方

- マップに散らばった**8個のアイテム（黄色）**を全部集めて、**右上の出口**へ向かいましょう。出口は全部集めると赤から緑に変わります。
- 警備員の**視界（床に映る扇形）**に入り続けると気づかれ、「！」が出て追いかけてきます。触れられると捕まります。
- **走ると足音**で近くの警備員に気づかれます。Shiftを押しながら歩く**忍び足**なら足音は出ず、見つかりにくくなります。
- スタート地点の小部屋は**安全地帯**です。ここでは見つからず、警備員も入ってきません。ただし一度外に出ると扉が閉まり、戻れません。
- 警備員は2種類います。**青**は決まった道を見回り、**紫**は気まぐれに歩き回ります。
- 警備員を見失わせても、最後に見た場所や逃げた方向を探しに来ます。油断は禁物です。

### お助けアイテム

20秒おきにマップに現れます。拾うと持ち歩けて、好きなときに使えます。

| アイテム | 色 | キー | 効果 |
|---|---|---|---|
| 透明化 | 白 | E / . | 10秒間、警備員の目に映らず、触れても捕まらない（足音は聞かれる） |
| スタン | ピンク | Q / / | その瞬間あなたを見ていた警備員は10秒、周りの警備員は5秒、動けなくなる |
| 音の罠 | 水色 | Space / \ | 足元に置くと3秒後に大きな音が鳴り、周りの警備員がそこへ調べに行く |

難易度によって出るアイテムが違います（下の表）。

## 難易度

| 難易度 | ライフ | お助けアイテム | ひとこと |
|---|---|---|---|
| 簡単 | 3 | 3種 | 青い警備員だけ。まずはここから |
| 普通 | 2 | 3種 | 紫の警備員がうろつき始める |
| 難しい | なし | 透明化・音の罠 | 警備員が鋭くなり、仲間を呼ぶ |
| 激ムズ | なし | 透明化・音の罠 | 遠くの警備員が回り込んで挟み撃ちにしてくる |
| 地獄 | なし | なし | 見つかった瞬間に追ってくる。助けは何もない |
| 理論値 | なし | なし | 地獄より見つかりやすく、見張り番・監視カメラ・開け閉めする扉・鳴る床がある。攻略ボットはクリアできた（はず） |

- ライフがある難易度では、捕まるとアイテムを2個落としてスタート地点に戻されます。ライフがなくなる（またはライフのない難易度で捕まる）とゲームオーバーです。
- 理論値の仕掛け：
  - 青緑の警備員（見張り番）は、その場から動かずに向きだけを変えます。
  - 監視カメラ（中央寄りの部屋の角）に映ると、近くの警備員が調べに来ます。
  - 区画の境目の真ん中の扉は、決まった間隔で開いたり閉まったりします。
  - オレンジの床（鳴る床）に乗ると音が出て、近くの警備員が調べに来ます。忍び足なら音は小さくなります。わざと鳴らしておびき寄せることもできます。
- 難しい以上では、アイテムを全部集めると紫の警備員があなたを決して見失わずに追ってきます。このとき、お助けアイテムは紫の警備員には効きません。

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| Shift | 忍び足 |
| E / . | 透明化を使う |
| Q / / | スタンを使う |
| Space / \ | 音の罠を置く |
| Tab | 視点の切り替え（全体 → 中間 → 近い） |
| F | 設定：足音の範囲の表示のオン・オフ |
| P | 一時停止・再開 |
| R | 同じ難易度でやり直す |
| M | 難易度選択に戻る |
| V | 難易度選択の画面で：選んでいる難易度のベスト記録を再生 |
| Esc | ゲームを終了（どの画面でも） |

起動するとタイトル画面が出ます。Enter を押すと難易度選択の画面に進みます。
難易度選択の画面では、↑↓で選んでEnter（または1〜6キー）で始めます。
一時停止中は時間も警備員も止まり、P で再開、R でやり直し、M で難易度選択に戻れます。

## ベストタイム

クリアすると、難易度ごとに一番速いタイムが記録され、難易度選択の画面に表示されます。記録を更新すると「新記録！」と出ます。記録はゲームを閉じても残ります。

記録はゲームのフォルダの `saves/records.json` に保存されます。このファイルを消すと記録がリセットされます。
ゲームのフォルダごと消したり、ダウンロードし直したりすると、記録も消えるので注意してください。

### ベスト記録のリプレイ

ベストタイムを更新すると、そのプレイがリプレイとして保存されます。難易度選択の画面で、[再生可] の付いた難易度を選んで V を押すと再生できます。

- 再生中も Tab（視点）・F（足音の範囲）・P（一時停止）が使えます。R で最初から再生し直し、M で難易度選択に戻ります。
- 再生のクリアは、ベストタイムには関係しません。
- リプレイは `saves/replays/` に、難易度ごとに1つ保存されます。
- この機能を入れる前のベストタイムには、リプレイがありません（次にベストを更新したときから保存されます）。
- ゲームが更新されて警備員の動きなどが変わると、古いリプレイは途中から動きが合わなくなります。そのときは「記録と動きが合わなくなりました」と出ます。

## 設定

- **足音の範囲の表示（F）**: 走っている間、足元に「足音が聞こえてしまう範囲」を表示します。この範囲にいる警備員は、足音を聞いて調べに来ます。
  - **赤い円**: 壁越しでも必ず聞こえる範囲
  - **黄色と黒の縞**: 間に壁がなければ聞こえる範囲（壁の向こうには届かないので、壁で切れた形になります）

  追跡中の警備員は、これより少し遠くの足音まで聞き取ります。最初はオンで、難易度選択の画面でもプレイ中でも切り替えられます。

## うまくいかないとき

- **「\」キーが反応しない**: 日本語キーボードでは、「\」が「¥」や「ろ」のキーに割り当てられていて反応しないことがあります。音の罠は Space キーでも置けます。
- **音が鳴らない**: 音のファイルが `src/stealth_game/assets/sounds/` にないと、音なしで動きます（起動したときに「音のファイルが見つからない」と表示されます）。
- **文字が英語で表示される**: 日本語のフォントが見つからない環境では、英語で表示されます。
